# Data Directory

This directory contains the datasets used for training and evaluation of lilybert.

## Structure

```
data/
├── raw/                 # Original LilyPond (.ly) files
├── processed/           # Preprocessed and tokenized data
└── README.md           # This file
```

## Raw Data (`raw/`)

Place your original LilyPond music notation files (`.ly` files) in this directory. These files should contain:

- Valid LilyPond syntax
- Musical compositions of various styles and complexity
- Proper headers with metadata (title, composer, etc.)

### Example LilyPond File Structure

```lilypond
\version "2.24.0"
\header {
  title = "Example Piece"
  composer = "Composer Name"
  genre = "Classical"
}

\relative c' {
  \time 4/4
  \key c \major
  \clef treble

  c4 d e f |
  g2 g |
  a4 a a a |
  g1 |
}
```

### Data Sources

You can obtain LilyPond files from:

- [IMSLP (International Music Score Library Project)](https://imslp.org/)
- [MutopiaProject](http://www.mutopiaproject.org/)
- [LilyPond examples](http://lilypond.org/examples.html)
- Your own compositions or transcriptions

## Processed Data (`processed/`)

This directory will contain preprocessed data generated by the preprocessing pipeline:

- `train.json` - Training dataset
- `validation.json` - Validation dataset
- Individual processed files with `.json` extension

### Preprocessing Steps

The preprocessing pipeline performs:

1. **Parsing**: Extract musical elements from LilyPond syntax
2. **Normalization**: Standardize notation and formatting
3. **Tokenization**: Convert to tokens suitable for language model training
4. **Structural Enhancement**: Add special tokens for musical structure
5. **Data Splitting**: Create train/validation/test splits

### Data Format

Processed files contain JSON objects with:

```json
{
  "text": "preprocessed LilyPond notation",
  "raw_text": "original LilyPond notation",
  "metadata": {
    "title": "piece title",
    "composer": "composer name",
    "key": "key signature",
    "time": "time signature"
  },
  "statistics": {
    "note_count": 42,
    "chord_count": 5,
    "total_elements": 50
  },
  "tokenized": {
    "input_ids": [101, 2023, ...],
    "attention_mask": [1, 1, ...],
    "token_count": 128
  }
}
```

## Usage

### 1. Prepare Raw Data

```bash
# Place your .ly files in data/raw/
cp my_music_collection/*.ly data/raw/
```

### 2. Run Preprocessing

```python
from maestrogpt.data import LilyPondPreprocessor

preprocessor = LilyPondPreprocessor()
processed_files = preprocessor.preprocess_directory(
    "data/raw",
    output_dir="data/processed"
)
```

### 3. Create Training Splits

```python
splits = preprocessor.create_training_data(
    processed_files,
    split_ratio=(0.8, 0.1, 0.1)
)
```

## Quality Guidelines

For best training results, ensure your raw data:

- **Is syntactically valid**: LilyPond files should compile without errors
- **Has diverse content**: Include various musical styles, keys, time signatures
- **Contains metadata**: Headers with title, composer, and other information
- **Is properly formatted**: Consistent spacing and structure
- **Has sufficient quantity**: Aim for hundreds to thousands of pieces

## Data Augmentation

The preprocessing pipeline can apply data augmentation:

- **Transposition**: Transpose pieces to different keys
- **Rhythmic variation**: Modify note durations while preserving structure
- **Ornament addition**: Add musical ornaments and articulations
- **Structure variation**: Modify repeat structures and sections

Enable augmentation in preprocessing:

```python
preprocessor = LilyPondPreprocessor(
    normalize_notation=True,
    add_special_tokens=True,
    enable_augmentation=True,
    augmentation_factor=2.0
)
```

## Troubleshooting

### Common Issues

1. **Empty processed files**: Check that raw LilyPond files are valid
2. **Tokenization errors**: Ensure proper encoding (UTF-8) for input files
3. **Memory issues**: Process large datasets in batches
4. **Quality issues**: Review and clean raw data before preprocessing

### File Validation

Validate LilyPond files before preprocessing:

```bash
# Check syntax with LilyPond compiler
lilypond --png -o /tmp/ data/raw/piece.ly

# Or use the built-in validator
python -c "
from lilybert.data import LilyPondParser
parser = LilyPondParser()
result = parser.parse_file('data/raw/piece.ly')
print(f'Parsed {len(result)} elements')
"
```
